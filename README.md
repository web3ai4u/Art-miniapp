# Алгоритмическая живопись — Telegram Mini App

Telegram Mini App для интерактивной генеративной живописи на **p5.js**. Основано на навыке [algorithmic-art](https://github.com/anthropics/skills/tree/main/skills/algorithmic-art) от Anthropic.

Бот присылает кнопку «🎨 Открыть Mini App», в которой открывается интерфейс со слайдерами, управлением сидом, пресетами и кнопками «Скачать PNG» / «Поделиться в Telegram».

## Возможности

- **Два алгоритма**:
  - **Flow Field** («Органическая турбулентность») — тысячи частиц по полю Perlin noise, накопительные следы.
  - **Quantum Harmonics** — фазовая интерференция синусоид на сетке, эмерджентные мандалы.
- **Сиды**: prev / next / random / прямой ввод. Одинаковый сид = одинаковая картина (детерминированность через `randomSeed` + `noiseSeed`).
- **6 слайдеров параметров** на каждый алгоритм: количество частиц, скорость, масштаб шума, затухание следа, толщина линии, октавы (для Flow Field); размер сетки, частота, скорость фазы, затухание, размер точки, контраст (для Harmonics).
- **8 палитр**: Anthropic, Закат, Море, Лес, Тундра, Мрак, Сакура, Сталь. Плюс три color-picker для ручной настройки.
- **6 пресетов-галереи**: «Шторм над тундрой», «Туман в долине», «Морской шторм», «Квантовый цветок», «Мандала ночи», «Резонанс» — готовые удачные комбинации.
- **Действия**: Сбросить параметры, Скачать PNG, Поделиться в Telegram (через `navigator.share` с файлом — работает в мобильном Telegram WebApp).
- **Бот-команды**: `/start`, `/help`, `/open`, `/seed` (детерминированные «сиды дня»).
- **Адаптивная вёрстка**: на десктопе — sidebar + canvas; в Telegram Mini App — canvas сверху, controls снизу.

## Стек

- **Node.js** ≥ 18
- **Express** — раздаёт статический Mini App
- **node-telegram-bot-api** — бот с polling
- **p5.js 1.7.0** (CDN) — генеративный движок
- **Telegram WebApp SDK** — интеграция с клиентом Telegram

Никаких сборщиков. Mini App — один самодостаточный `public/index.html`.

## Быстрый старт

### 1. Установите зависимости

```bash
cd telegram-mini-app
npm install
```

### 2. Создайте бота в @BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`.
3. Задайте имя и username.
4. Скопируйте **Bot Token**.

### 3. Поднимите локальный сервер + HTTPS-туннель

Telegram требует, чтобы URL Mini App был **HTTPS**. Для локальной разработки используем ngrok.

В двух терминалах:

**Терминал 1** — сервер:

```bash
cp .env.example .env
# Откройте .env и впишите BOT_TOKEN от BotFather
# WEBAPP_URL пока оставьте как есть — заполним после ngrok
npm start
```

Сервер поднимется на `http://localhost:3000`.

**Терминал 2** — ngrok-туннель:

```bash
npm run ngrok
# или: ngrok http 3000
```

ngrok выдаст строку вида:

```
Forwarding   https://a1b2-203-0-113-42.ngrok-free.app -> http://localhost:3000
```

Скопируйте HTTPS URL.

### 4. Впишите HTTPS URL в .env

```bash
# .env
BOT_TOKEN=123456:ABC-DEF...
WEBAPP_URL=https://a1b2-203-0-113-42.ngrok-free.app
PORT=3000
```

Перезапустите сервер (`Ctrl+C`, затем `npm start`).

### 5. Настройте кнопку Mini App в @BotFather (опционально, но рекомендуется)

Чтобы кнопка «Open» работала прямо в меню бота (а не только через инлайн-кнопку):

1. @BotFather → `/mybots` → выберите вашего бота.
2. **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Отправьте текст кнопки (например, `🎨 Открыть генератор`).
4. Отправьте URL Mini App (ваш ngrok HTTPS URL).

После этого в чате с ботом появится кнопка-меню слева от поля ввода, которая будет открывать Mini App.

Альтернатива — отправить боту `/start`, и он пришлёт инлайн-кнопку.

### 6. Откройте бота в Telegram

Напишите боту `/start`. Нажмите кнопку «🎨 Открыть Mini App». Откроется генератор.

## Использование

1. **Выберите алгоритм** — кнопки `Flow Field` / `Quantum Harmonics` вверху сайдбара.
2. **Крутите слайдеры** — живопись обновляется в реальном времени. Некоторые параметры (число частиц, октавы, размер сетки, частота) вызывают полную регенерацию, остальные подхватываются на лету.
3. **Меняйте сид** — кнопки `← Назад` / `Вперёд →` / `↻ Случайный`, или введите число вручную и нажмите Enter.
4. **Палитры** — кликните по одному из 8 цветовых свотчей в секции «Палитра», либо настройте три цвета вручную через color-picker.
5. **Галерея** — кликните по пресету, чтобы применить готовую комбинацию параметров + палитры + сида.
6. **Скачать PNG** — кнопка `⬇ PNG` сохранит файл вида `algorithmic-art-flowfield-12345.png`.
7. **Поделиться в Telegram** — кнопка `↗ В Telegram` откроет системный шеринг-лист с готовой картинкой (на iOS/Android в Telegram WebApp). Если шеринг с файлами недоступен, fallback — Telegram share-ссылка.

## Деплой в продакшн

Когда наиграетесь локально, можно задеплоить Mini App на любой хостинг с HTTPS:

- **Vercel / Netlify / Cloudflare Pages** — статический `public/` деплоится как сайт. Бот при этом остаётся на вашем сервере (или можно переписать на serverless-функции).
- **Render / Railway / Fly.io** — Express-сервер целиком, дают HTTPS из коробки.
- **Свой VPS** — `node server.js` + Caddy/Nginx с Let's Encrypt.

После деплоя обновите `WEBAPP_URL` в `.env` на боевой HTTPS-адрес и перезапустите бота.
